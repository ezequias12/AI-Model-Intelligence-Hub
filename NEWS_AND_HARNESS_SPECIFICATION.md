## 2. Trust tiers

Tier 1:
- official provider pages
- official docs
- official changelogs
- government/primary documents where applicable

Tier 2:
- established reporting
- reputable technical publications
- Artificial Analysis
- Hugging Face

Tier 3:
- social posts
- community discussion
- uncorroborated discovery signals

Do not equate trust tier with political viewpoint.

## 3. Deduplication

Canonicalize URL.
Hash normalized title/domain/date.
Cluster secondary stories around the same event where possible.
Prefer primary-source canonical item as cluster anchor.

## 4. Summaries

Store:
- source title
- canonical URL
- published date
- discovered date
- source excerpt only when permitted
- short derived summary
- linked entities

Do not mirror full articles.

LLM summary must:
- be optional;
- be structured;
- contain no unsupported facts;
- retain source URL;
- degrade gracefully when no model key exists.

## 5. Social / X

- account id
- handle
- post id

- text/excerpt
- published at

- linked entities

Maintain monitored-account registry by category:
- model providers
- executives/researchers
- benchmark organizations
- coding harnesses
- coding-harness founders/official accounts

## 10. Harness source strategy

Prefer:
1. official pricing page
2. official plan docs
3. official changelog
4. official GitHub releases
5. official social
6. secondary reporting

For pricing pages without structured APIs:
- controlled HTML parser;
- schema validation;
- selector tests/fixtures;
- fail loudly when page shape changes;
- save raw hash;
- do not silently write null/zero prices.

## 11. World & Politics source policy

Use reliable current sources and primary documents where practical.

Requirements:
- explicit source;
- neutral summary;
- event date vs publication date;
- multiple sources for contested/breaking stories when needed;
- no candidate/party recommendations;
- no electoral predictions generated by the app;
- no ideological sentiment score.

Store domain separately so political content does not influence model/harness recommendations.
